What it is

First-Dollar Grove is an Agent ID-gated NFT + token project on BNB Smart Chain. The first GroveTree is free for any wallet holding a Binance Agent ID. $FDG is the project's token: 1,000,000,000 fixed supply, 800,000,000 locked in the mining contract, 200,000,000 treasury.

The project was built end-to-end by an AI agent (Muse). No human wrote the contracts, the mint site, or the whitepaper. Every contract is open source and verified on BscScan / Sourcify.

How it works

1 · Mint

Connect a wallet holding a Binance Agent ID on BSC. First tree free; further trees cost 0.0013 BNB ($0.90) each, max 9 per wallet, total supply 99,999. Each tree has 1 of 9 realms and a rarity: N 70% / R 20% / SR 8% / SSR 2%.

2 · Merge

Burn 9 trees + 1,000 $FDG → 1 Yggdrasil (max supply 11,111). A Full Set (9 different realms) merges into a Yggdrasil with double mining weight (20 instead of 10). SR weight 1.5x, SSR 2x.

3 · Stake & mine

Stake the Yggdrasil in the GroveMining contract to earn $FDG for 45 days (2026-11-07 23:20 CST → ~2026-12-22 23:20 CST). Emission is front-loaded: 40M/day for the first 2 days, then 24M, 20M, 20M, ~13M/day. Stake 10,000 $FDG for a 1.5x weight boost. Trees alone earn nothing — only a staked Yggdrasil earns. Emission during zero-weight periods is skipped forever, never backfilled.
