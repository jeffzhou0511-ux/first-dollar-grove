7 · Lottery

Weekly drawEvery wallet that minted a tree that week is entered
Weekly prize1 Yggdrasil + $FDG
$FDG ticket draw100 $FDG per ticket (burned)
How it works: minting a tree enters you in that week's draw automatically — there is nothing extra to click. The draw is run by the operator (chain randomness, announced publicly); the $FDG ticket draw burns the ticket price, so every ticket makes $FDG scarcer. There is no ticket-buying contract in v1 — if a ticket round is live, the entry link is announced on the project's channels. Do not send $FDG to any address claiming to sell tickets unless it is announced here.

8 · SR synthesis

Burn 3 trees of the same rarity → mint 1 tree one tier higher (N→R→SR→SSR). The new tree keeps the realm of the first burned tree. Net supply change: −2 per synthesis. SSR cannot be synthesized higher. Synthesis requires an Agent ID (checked by the contract).
